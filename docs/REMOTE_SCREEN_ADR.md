# 远程观看与人工接管

实施前草案，依据 [#898 第 5.6、7.5 和 10 节](https://github.com/DingHappy/VortoOne/blob/c1f43e82cc770b98e270245558ad6cb68d9b6ae9/docs/HOME_AND_MEMBERS_DESIGN.md)。

当前 [网站人工接管](WEBSITE_HANDOFF.md) 依赖用户和浏览器位于同一台电脑。主分支已有连接器身份和文件通道。远程屏幕需要独立的数据连接，先实现浏览器，再考虑整个桌面。

## 授权

- 家从真人登录会话取观看者身份，从运行端登记取角色负责人和发起人，从设备授权记录取配对人。实际观看和接管前还要核对屏幕与当前回合、设备及连接代次的绑定。浏览器状态接口只查五档级别和角色可见性。
- 电脑由配对人通过本机设置决定是否向团队共享。未共享时，只有配对人可以打开屏幕，仍要满足级别要求。管理员与空间所有者也受这一限制。配对、共享或屏幕绑定记录缺失时拒绝打开。
- 五档按最高身份组合并。自己的范围由可信的角色负责人、配对人和发起人记录确定。自己的浏览器允许在该范围内看浏览器。自己的电脑还可看该范围内的桌面。所有浏览器继续保留自己的桌面权限。所有电脑允许团队范围内的两种屏幕。
- 观看默认为只读。人工接管单独确认并记录审计。登录请求交给资源主人或设计允许的团队审批人，且需要相同的屏幕权限。
- 打开观看、发送每批画面、转发每次人工输入和交还控制前都要复核当前会话、身份组、共享设置及连接代次。撤权断开观看并停止转发输入。

## 生命周期与数据

- 成员从自己的已登录会话为电脑生成单次配对码。授权绑定当前家的信任代次和当次成员身份，设备只出现在配对人的列表里。被移出空间后，现有连接和未使用的配对码失效。成员设备目前支持身份和在线状态，使用控制协议第 1 版。
- 电脑继续主动向家连接。屏幕使用独立、短时且绑定到已认证连接代次的授权。连接重建后重新授权。
- 只在有授权观众时传画面。画面和人工输入只转发给当前会话，留在内存。审计存参与者、设备、时间和结果。审计、模型上下文、任务记录和记忆均不接收画面、按键或登录凭据。
- 人接管时锁住该屏幕的角色输入。控制交还后，角色重新观察再继续。断线或撤权后，回合暂停等待确认。

## 验证顺序

先验证身份组授予和屏幕状态 API 的五档判断。浏览器数据适配完成后，再用两个账号核对私有电脑、角色归属、发起人、级别降权，以及接管期间角色停手和交还后重新观察。随后在分开的家与 Desktop 上验收一次登录接管，再验证整个桌面。

## 私有浏览器数据通道

家已接入只读画面转发。连接器为本机选定的浏览器窗口主动打开独立数据连接，每次开放绑定当前配对和控制连接代次，有效期五分钟。只有同源登录的配对人且具备自己的浏览器级别才能观看。家按观众的请求索取单张 PNG，限制尺寸、体积和频率。每张图在转发时重新核对会话、级别和配对。画面留在内存中，审计只写观看者和设备等元数据。

成员退出会话后停传画面。所有者现有登录共享同一个凭据，退出时会结束当前家中已打开的所有者预览。

VortoOne Dev 的「连接的电脑」可通过系统确认窗口打开专用 Chromium。它使用新建的临时浏览器配置，关闭资料同步，只采集打开时的初始标签页。DevTools 走本机进程管道。关闭该标签页、停止分享、到期、退出 App 或控制连接中断都会结束分享。重新连接后需要在本机再次确认。

配对人可以在家中打开「设置 → 设备 → 连接的电脑」，点击「查看浏览器画面」发起观看。关闭页面或点击「停止查看」即可结束观看。观看端每次只请求一张图，关闭或失效时清除当前帧。自动化用合成浏览器和画面验证本机分享命令、连接代次、按需抓图、到期与关闭路径。无界面 Chromium 已验证空白页抓图，独立设备之间的桌面验收待进行。

设备页在前台随电脑列表刷新开放状态。只有当前配对人具备浏览器级别且对应分享仍有效时，家才返回可查看状态。此状态只包含布尔值。打开观看和转发每帧仍重新核对会话、授权和连接代次。真实 HTTP 与 WebSocket 的回环测试串联设备端抓图、开启及停止状态、家中转发与观看。

## 私有桌面观看

在 macOS 14 或更新版本的 VortoOne Dev 中，本机人员可从「连接的电脑」选择「选择并分享显示器」。确认配对的家后，须在 macOS 系统选择器中选定一块显示器。选定后才建立分享通道，有效期五分钟。可从同一窗口立即停止分享。

配对人凭同源登录会话与自己的电脑级别，从家中的设备设置打开「查看桌面画面」。每次开放只允许一处只读观看。画面按需生成，以限频、限大小的 PNG 在内存中转发。每帧复核登录、身份组、配对记录和连接代次。审计保存观看身份和设备等元数据。

停止分享、到期、退出应用或控制连接断开都会结束本次开放。重新连接后须在本机重新确认并选择显示器。权限失效后停止向该会话转发并清除观看端的当前帧。自动化使用合成画面验证连接路径。系统选择器的实机授权和独立设备之间的观看留待验收。

### 私有桌面接管

macOS 15.2 或更新版本可使用「分享并允许接管」。本机人员先确认配对的家，再在系统选择器选定一块显示器。原生辅助程序核对所选显示器的身份和系统辅助功能权限。本机一次开放一处接管，分享窗口显示是否已有人接管，并提供停止按钮。

具备桌面权限的配对人打开画面后点击「接管桌面」。点击坐标限于所选显示器。文字只发到同一帧前后仍聚焦、位于该显示器上且可编辑的普通文本框。每次操作须等待同一观看连接收到新画面。审计只存接管开始和结束的身份、设备与时间。

点击「交还控制并结束分享」、离开观看页面、撤权、断线或到期会结束本次接管。重新取得控制须从本机重新确认。

#### 本机任务浏览器的停手与恢复

同一 VortoOne Dev 安装的连接器与本机任务浏览器共用一个本地控制锁。观看阶段可以继续观察。配对人点击「接管桌面」时，若任务浏览器正在执行已批准的操作，观看页会提示稍后重试。取得控制后，本机任务浏览器暂停执行和读取。辅助程序退出后才释放锁。

每次取得控制都会更新授权代次。交还、断线或撤权后，接管前未执行的确认与旧接管卡画面随之失效。任务浏览器尚未打开时须重新确认打开。窗口仍在时，由所有者重新确认，角色核对原窗口和站点并读取页面当时的内容。本机系统授权与双设备实机流程留待验收。

## 当前回合的登录确认

VortoOne Dev 主助理对话复用原网站确认显示登录接管卡。用户在运行端的专用窗口完成登录后，从卡片提交核对。每次核对绑定原回合、原浏览器和租约，并复查站点来源及授权。

VortoOne Dev 的本机「连接的电脑」窗口提供「任务专用浏览器」开关，默认关闭。通过系统确认开启后，已登录的所有者可从本机家的主助理对话发起新回合。每次打开公开 HTTPS 网站都要确认。浏览器使用本回合临时资料，回合结束时关闭并清理。关闭设置或退出登录会让当前回合不再取得画面或继续读取页面；重新开启只给新发起的本机回合授权。

同源登录的所有者可以从接管卡点击「开始查看画面」。只读连接逐张请求画面，抓图间隔至少 500 毫秒，每个确认同时只允许一处观看。画面来自主助理在本回合创建的临时浏览器，浏览器须仍在等待人工确认。抓图前后都核对站点、页面和授权。检测到登录表单、嵌入页面或带查询或片段的地址时关闭查看并清除上一帧。点击「停止查看」、切走页面、确认结束、窗口关闭、回合换绑或所有者退出时结束查看。图片只在内存中转发，审计记录观看者与确认编号。

## 配对电脑上的任务窗口

所有者在主助理提出「在配对电脑上人工核对」并提供公开 HTTPS 站点源地址时，主助理可发出一次网页核对。接管卡只为所选、已在线的所有者配对电脑生成一次性任务码。码最长有效两分钟，与当前回合、审批和电脑连接代次绑定。重新生成使旧码失效。家只在生成任务码时把它返回给所有者，并将有效的任务码留在内存。

在所选电脑的 VortoOne Dev「连接的电脑」打开任务浏览器，输入任务码并通过系统确认。连接器打开独立的空白窗口，本机操作人在地址栏打开接管卡指定的网站。画面只从原接管卡按需查看，页面须位于原站点并通过保护检查。登录表单、其他站点、可见嵌入内容以及带查询参数或片段的页面都会停传。

在配对电脑打开任务窗口时，可以选择「允许所有者从接管卡操作网页」，并在系统对话框确认。所有者打开画面后点「接管页面」，就能在指定站点通过保护检查的页面里点击、滚动、向普通输入框发送文字或退格。每次操作都依赖同一接管连接收到的最近一帧。连接器在独立的页面检查中重新核对站点、文档和视口，再执行操作。到达受保护页面时停传画面。审计登记接管开始和结束时间。

配对电脑还可在本次确认中允许一次本站登录。打开同源 HTTPS 的标准密码表单后，原接管卡显示站点地址及账号、密码输入框。若密码提交后出现本站的标准数字验证码表单，接管卡会切换为验证码输入。所有者亲自输入并确认各步。配对电脑为每一步提供独立的一次性公钥，家只转发密文。配对电脑重新核对原文档、表单和提交地址。每步最多提交一次，审计只记录提交动作。

自提交密码起停止传输图像，接管卡仅显示登录进度和下一步输入。验完本站的新页面后，接管卡释放控制权，由所有者确认继续原任务。跨站 SSO、其他验证方式、非标准登录表单及付款仍在配对电脑上处理。表单更换、过期或权限失效会拒绝提交。

结束接管后，所有者从原卡片点「我已完成，核对并继续」。家要求原窗口重新核对是否已回到可查看的原站点。角色收到真人确认和站点核对结果。确认结束、退出会话、撤权或设备断线后停止分享并清理临时窗口。双设备实机验收仍待进行。
